## ⚙️ Déploiement

Ce projet est déployé automatiquement via GitHub Actions dès qu’un push est effectué sur la branche `main`.

📁 Fichiers de déploiement :
- `.github/workflows/firebase-deploy.yml`
- `.firebaserc`
- `firebase.json`
- `public/index.html`
